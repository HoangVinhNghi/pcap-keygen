How activation works

  1. The user opens PCAP Analyzer; the activation screen shows a Seed Code for that computer.
  2. They send you the Seed Code; you generate the Gen Key here and send it back.
  3. The key works on that computer only. A new computer, hostname or network adapter gives a new Seed Code.
  4. The key expires after the chosen period (3 months by default). The app reminds the user 14 days before; issue a new key for the same Seed Code to renew.
